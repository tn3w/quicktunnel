quicktunnel

Share a local web server under a public https://xxxx.{domain} address:

curl -s https://t.{domain}/3000|sh

Replace 3000 with your port. Needs only ssh, curl and openssl. Press Ctrl+C to stop.

Every tunnel serves user content from someone's own computer, not from {domain}. Visitors see a warning before the first page. Report abuse to abuse@{domain}.
